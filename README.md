# MFE-KIT Core

This is the core package for **Micro Frontends (MFE)** in the [MFE-KIT](https://github.com/mfe-kit) ecosystem.

## Important

To create an MFE using MFE-KIT, please follow the instructions in [DEV-TOOLS](https://github.com/mfe-kit/dev-tools).

## Features

The core package includes:

- Decorators
- Translation service
